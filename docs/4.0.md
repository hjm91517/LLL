# 4.0 改造记录

## 目标

| 需求 | 处理 |
|---|---|
| 音乐页加网易云登录按键 | 播放卡片上方分段控件右侧新增「网易云登录」按钮，未登录直接开面板，已登录变账号菜单 |
| 灵动岛图标 100% 取网易云曲图 | `LLLNowPlaying` 增加 `artworkURL`；内核切歌先查 `LLLCloudVIP` 磁盘缓存，没有才异步拉，拉到立刻刷岛；本地曲目才回落到音符占位 |
| VIP 歌曲可听 | 新增 `LLLCloudVIP`，eapi 通道多档回退（player v1 exhigh/lossless → download v1 → 老明文 br=320000 → 外链兜底），每档都做 HEAD 探测，302→403 的假地址直接丢 |
| 登录绕风控 | 新增 `LLLCloudRequest`：按接口类别串行控速（读 2/s、取流 4/s、登录 1/5s）、指数退避、命中 -460/401/503 时全局静默 8~20 秒；Cookie 统一带 `os=ios; appver=9.1.60`；网页登录走站点自己的页面 |
| 本地/网易云切换跳页 | 音乐页数据源与播放内核解耦（`LLLMusicController`），切源只换队列不动播放器；`numberOfRows` 与 `cellForRow` 共用唯一取数入口，越界不可能 |
| 卡片播放键不管用 | 全部按键转 `LLLPlayerCore`，内核自己判断当前源与队列，不再依赖 `audioPlayer` 是否存在 |
| 顺序播放失效 | 内核统一接管 `AVPlayerItemDidPlayToEndTimeNotification` + `AVAudioPlayerDelegate`，顺序/单曲/随机对本地与网易云同时生效 |

## 新增文件

- `core/LLLPlayerCore.{h,m}` — 统一播放内核
- `overlay/LLLIslandCoreBridge.{h,m}` — 灵动岛 ↔ 内核桥
- `ui/LLLCloudRequest.{h,m}` — 请求层（节流/退避/风控识别）
- `ui/LLLCloudVIP.{h,m}` — 音源多档回退 + 封面缓存 + VIP 打标
- `ui/LLLMusicController.{h,m}` — 音乐页数据源/播放解耦
- `ui/MainViewController+Music4.{h,m}` — 页面接线
- `ui/MainViewController+Legacy4Shim.m` — 旧方法重定向
- `ui/LLLMusicTab4.m` — 表格数据源统一入口
